# public/

Assets estáticos del renderer. Vite los sirve en la raíz (`/archivo.ext`).

## Mascota

Coloca aquí el sprite pixel art del cuy con el nombre exacto:

```
public/mascot.png
```

Recomendado: PNG cuadrado, fondo transparente, **32×32** o **64×64** px (se escala con `image-rendering: pixelated` para mantener el look retro).

Si el archivo no existe, la app hace fallback a 🐹 automáticamente.
